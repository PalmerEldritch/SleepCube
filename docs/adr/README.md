# Architecture Decision Records (ADR)

This folder tracks design decisions that materially affect firmware architecture.

## Naming

- `ADR-XXXX-short-title.md`

## Lifecycle

- `Proposed` -> `Accepted` -> `Superseded` (if replaced later)

## Rule

Create or update an ADR when changing:

- storage strategy
- decoding library
- audio pipeline architecture
- major interface contracts
